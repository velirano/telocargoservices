# telocargoservices.com

Site vitrine de **Telo Cargo Services** — commissionnaire agréé en douane (CAD) et MAD, transport maritime, aérien et terrestre depuis Antananarivo et Toamasina.

- Site statique : un seul fichier `index.html` (HTML/CSS/JS, sans dépendance de build).
- Hébergement : OVHcloud (déploiement Git depuis la branche `main`).
- Aperçu local : ouvrir `index.html` dans un navigateur.
